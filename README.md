# محمد عبدالله اللصاصمه — مختبر الإبداع الرقمي

موقع شخصي وملف أعمال تفاعلي باللغة العربية، يجمع بين الخبرة في هندسة الكهرباء والاتصالات، مشاريع الألياف الضوئية وFTTH وCCTV، والتجارب التعليمية الرقمية والألعاب والوسائط.

## الروابط

- **الموقع المنشور:** https://creativeshow-npsowsgu.manus.space
- **GitHub Pages:** https://mohammadallasasmeh90-design.github.io/mohammad-creative-showcase/
- **المستودع:** https://github.com/mohammadallasasmeh90-design/mohammad-creative-showcase

## ما يحتويه الموقع

يتضمن الموقع صفحة تعريف شخصية، قسمًا للخبرات المهنية، معلومات التواصل، معرض مشاريع، ألعابًا وتجارب تعمل داخل الموقع، عارضًا لقصة الأطفال، وصفحة للموقع الإلكتروني المرفق، بالإضافة إلى رابط تحميل السيرة الذاتية.

## التشغيل محليًا

```bash
pnpm install
pnpm dev
```

## النشر

يتم بناء الموقع ونشره تلقائيًا إلى GitHub Pages عند كل تحديث على الفرع `main` بواسطة GitHub Actions في الملف `.github/workflows/deploy-pages.yml`.
